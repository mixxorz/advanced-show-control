# Keyboard Shortcuts

`CmdOrCtrl` means Command on macOS and Control on other supported platforms.

## Fixed File Shortcuts

| Command | Shortcut |
| --- | --- |
| **New Session** | `CmdOrCtrl+N` |
| **Open Session...** | `CmdOrCtrl+O` |
| **Save Session** | `CmdOrCtrl+S` |
| **Save As...** | `CmdOrCtrl+Shift+S` |

## GO And CUE

| Action | Default |
| --- | --- |
| **GO** | `Space` |
| **CUE** | `C` |

Change these shortcuts in [Settings](../settings.md#active-in-v2). Select the shortcut control, press the combination, and confirm the displayed result. Press `Escape` to cancel. `Tab` can be assigned. A shortcut cannot duplicate the other action or a fixed file shortcut.

Shortcuts do not operate while you are entering text or working in a dialog. To use GO, select an active cue list, cue a linked entry, confirm **Cued**, and confirm **SAFE** is off. Holding the key does not repeat GO or CUE.
