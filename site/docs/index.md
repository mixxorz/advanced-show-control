# Advanced Show Control

## Smooth scene changes for Waves eMotion LV1

Advanced Show Control adds timed fader and pan moves to your existing LV1 scenes. Use it to create smooth transitions between parts of a show without changing the way you build scenes on the console.

You choose which channels can move, store the levels you want them to reach, and set the transition time. When you recall the scene, Advanced Show Control moves those controls from their current positions to the stored values.

![Advanced Show Control with the Scenes screen open.](assets/screenshots/application-shell.png)

### Scene fades

Add a fade to any LV1 scene. Each scene can have its own channels, target values, and transition time. A fade can be as short as an immediate cut or as long as 120 seconds.

### Cue lists

Arrange scenes in show order without rearranging the scene list in LV1. Prepare the next cue, confirm it in the status bar, and recall it with **GO**.
